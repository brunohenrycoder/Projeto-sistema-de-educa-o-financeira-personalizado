# Aurora — Referências de Design

Este diretório reúne o guia visual e os protótipos PNG usados como referência para o refinamento visual do frontend.

- `DESIGN_GUIDE.md`: orientações de estilo e limites das alterações.
- `prototypes/`: capturas de protótipos do MagicPath.

## Instrução para o OpenCode
Antes de realizar uma melhoria visual, consulte `DESIGN_GUIDE.md` e a imagem correspondente em `prototypes/`, além do RF e da implementação atual. Trate os protótipos como referência de apresentação, não como autorização para mudar funcionalidades ou regras.

Login e Cadastro estão aprovados: não redesenhar nem alterar essas telas.
